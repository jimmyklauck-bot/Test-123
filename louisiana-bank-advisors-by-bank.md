# Louisiana Bank Wealth Advisors, Organized by Bank

Compiled 2026-09-06. Companion to `louisiana-banks-wealth-management.md`, which covers which banks have programs. This file covers who the people are.

**Read this first.** WebFetch was blocked for every external domain, so none of the bank team pages, advisor bio pages, or FINRA BrokerCheck could be opened directly. Everything below came through web search of those same pages. That has a specific effect on the results: where a bank publishes a roster on an advisor-facing microsite (Red River, First Federal, HB Financial), coverage is good and emails came through. Where the roster only lives behind a locator or a JavaScript team page (Hancock Whitney, Regions, Gulf Coast, CNB), I got the program and one or two names but not the roster.

**Verify before dialing.** Direct-dial numbers and emails below came from aggregators as often as from the firms. Run BrokerCheck on any advisor before the call.
